# 实验参考资料

五个基础练习的接口、用例与官方检查器以同一个参考提交为准。章节编号为 ch3、ch4、ch5、ch6、ch8。[TanGram-rCore 指定版本](https://github.com/rcore-os/rCore-Tutorial-in-single-workspace/tree/d6330a6db1f81c8c1cfba5ec3db9923199398f24)

| 学习环节 | 先读什么 | 公开资料 |
|---|---|---|
| 第一次启动 | Rust 裸机环境、特权级和 SBI 输出 | [rCore 教程书](https://rcore-os.cn/rCore-Tutorial-Book-v3/) · [RISC-V Reader 中文版](http://riscvbook.com/chinese/RISC-V-Reader-Chinese-v2p1.pdf) |
| ch3 系统调用 | 任务上下文、系统调用和分时复用 | [rCore 实验指导](https://learningos.github.io/rCore-Tutorial-Guide/) |
| ch4 虚拟内存 | 地址空间和页表权限 | [OSTEP 中文版](https://pages.cs.wisc.edu/~remzi/OSTEP/Chinese/) · [CSAPP 中文资料](https://hansimov.gitbook.io/csapp/) |
| ch5 进程调度 | 进程接口、调度策略和调度比例 | [OSTEP 中文版](https://pages.cs.wisc.edu/~remzi/OSTEP/Chinese/) |
| ch6 文件系统 | 文件接口、inode 与硬链接 | [OSTEP 中文版](https://pages.cs.wisc.edu/~remzi/OSTEP/Chinese/) · [LearningOS 实验代码](https://github.com/LearningOS/rCore-Tutorial-Code/) |
| ch8 同步 | 锁、信号量和并发错误 | [OSTEP 中文版](https://pages.cs.wisc.edu/~remzi/OSTEP/Chinese/) · [LearningOS 实验测试](https://github.com/LearningOS/rCore-Tutorial-Test/) |

需要按阶段练习时，可补充参考开源操作系统训练营的课程安排。[2025 年秋冬季训练营](https://opencamp.cn/os2edu/camp/2025fall)

LearningOS 代码和测试用于阅读同类实验，运行本项目时使用仓库内锁定的 TanGram-rCore 用例。截图中的资料均为赛题公开参考。实际采用哪套本校实验材料尚无可核验记录。

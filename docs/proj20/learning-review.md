# 学习复盘与对照

本项目面向初次学习 Rust 和操作系统内核的学生。每章都先预测程序行为，再运行测例，从串口或单元测试找到证据，最后回答一个可以用代码验证的问题。

## 两次可记录的练习

| 主题 | 练习 A | 练习 B |
|---|---|---|
| 虚拟内存 | 判断只读页写入失败的原因 | 判断撤销映射后读取失败的原因 |
| 同步 | 判断同一线程重复加锁的结果 | 判断有线程能先释放资源时是否应报死锁 |

任选一个主题。一次沿参考教程的该章练习定位问题，另一次用本项目的指导、日志和分层提示。记录两次题目与顺序。题目难度和练习顺序可能影响结果，比较时注明。

计时从看到题目开始，在首次提交正确解释并能指出支持证据时结束。找不到答案时记录实际用时和停在哪一步。另记使用的提示层级、自查结论和能否把解释迁移到另一例。编译或下载单独计时。

## 三方比较的证据

参考教程提供章节说明、练习接口和官方检查器。本项目沿用同一批官方测例，另提供从串口结果到源码的逐步提示、失败到复验的实际记录和重点路径的独立测试。前两者可以直接在同一云端实例复现。

本校环境用课程讲义、实验平台或实验任务来核对。优先比较等价任务的可观察信息、独立定位所需步骤、提示依赖和耗时。现场未采集或缺乏可比任务时，标记该列缺失。当前个人用时和本校材料待实际记录。
